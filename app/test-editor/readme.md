# 編輯器測試頁面

訪問：http://localhost:3000/test-editor

## Task 8 新功能

### 文字元件
- **雙擊編輯**：雙擊文字元件進入編輯模式
- **即時更新**：輸入時即時更新內容
- **Enter 換行**：Enter 鍵換行，Escape 或點擊外部完成編輯
- **樣式保留**：編輯時保留字型、大小、顏色、對齊等樣式

### 圖片元件
- **雙擊更換**：雙擊圖片進入編輯模式
- **上傳圖片**：支援從本地上傳圖片（最大 5MB）
- **URL 輸入**：直接輸入圖片 URL
- **格式支援**：JPG, PNG, GIF
- **自動轉換**：上傳的圖片自動轉為 base64 儲存
- **錯誤處理**：圖片載入失敗時顯示提示

### RSVP 表單元件
- **雙擊配置**：雙擊表單進入設定模式
- **欄位切換**：勾選要顯示的欄位（姓名、Email、出席意願、留言）
- **即時預覽**：配置後立即看到表單樣式
- **完整樣式**：包含標籤、輸入框、單選按鈕等完整表單元素

## 使用方式

1. 從右側元件庫添加元件到畫布
2. 單擊選取元件
3. 雙擊進入編輯模式
4. 編輯完成後點擊外部或按 Escape
5. 可使用工具列的 Undo/Redo 功能

## 注意事項

- 編輯模式下無法拖拉元件
- 編輯模式會顯示「編輯中...」提示
- 選取的元件會有藍色外框
- 編輯中的元件不會顯示調整控制點
